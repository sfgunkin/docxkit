## 1. One regex, and the fix that stopped six lines short → BACKLOG S1

`_table_layout.py:81`:

```
_TCW_RE = re.compile(r'<w:tcW w:w="[^"]*" w:type="\w+"/>')
```

and twelve lines below it, `_TBLW_RE`, rewritten to `<w:tblW\b[^>]*/>`
with a comment naming the Corruption and Wages manuscript, the
`w:type="auto" w:w="0"` it carries, and "the same failure the bookmark
patterns in `_xml` carry the same warning about". The warning did not
travel up the page.

The consequence is not a miss. `_set_tc_w` (line 481) reads an empty
match as "no width here" and INSERTS one — so a type-first cell ends
with two `w:tcW` in one `w:tcPr`, which is the doubled-property shape
the 2026-08-20 round fixed in eight writers. Word takes the first, the
old width. `fit_columns` returns a plan; nothing reads the cell back.

**Corpus, 2026-09-03**, 150 of 2,854 documents strided, `document.xml`
only: 84 spell `w:w` first, 5 spell `w:type` first, 3 carry both orders
in one document. The same 5 spell `w:tblW` type-first.

**Census.** Of 231 patterns compiled from a literal (AST; the 08-15
review counted 158 the same way, so the registry grew 46 % in nineteen
days), four spell two namespaced attributes in sequence:

```
  _cite_audit.py:64    one attribute per alternative       not order-bound
  _xml.py:532          one attribute per element           not order-bound
  styles.py:176        lookaheads                          not order-bound
  _table_layout.py:81  w:w then w:type, literally          THE ONE
```

`test_regex_registry.py` holds the self-closing hazard over every
container element, and holds. It does not hold this one, and the count
is a one-line addition to it.

## 2. The documented entry point is the one write that is not atomic → BACKLOG S2

`edit_in_place` is what the README, the `docxkit` skill and
`tools/consumers.txt` hand to a paper script. It has **zero callers in
`src/`**. What it does, `package.py:494–505`:

```
  shutil.copy2(path, work)          # source -> TEMP, unretried
  zipfile.ZipFile(work)             # bare read
  write_docx(out, parts, order)     # atomic — into TEMP
  shutil.copy2(out, path)           # TEMP -> the manuscript, a COPY
```

The atomic write lands where atomicity buys nothing, and the manuscript
is then overwritten by a copy — a destination opened for writing and
streamed into, which `_replace_atomically`'s docstring calls "exactly
the interruptible write being avoided", and `write_docx`'s says matters
here because "the machine this runs on has unreliable mains power".
The `copy2` at the top is `read_parts` without the six-attempt retry
that was added for the OneDrive `[Errno 13]` race on 2026-08-20.

The test at `test_package.py:83` — the file is intact when the transform
raises — is true because the write never starts. Nothing covers a write
that stops. The fix is five lines and shorter than what is there (the
entry in `BACKLOG.md` has them); the test is the `os.replace`-raises
shape `test_package.py:186` already uses for `write_docx`.

## 3. A predicate that cannot tell two errors apart → BACKLOG S2

Measured, this machine: a file with only `S_IREAD` set and nothing
holding it. `open(p, "r+b")` → `PermissionError errno=13 winerror=None`.
`is_locked(p)` → `True`. Clear the bit → `False`.

A sharing violation reaches Python through the same CRT path with the
same errno, so `package.py:168`'s `except PermissionError` cannot
distinguish them and does not consult the mode, which can.
`assert_unlocked` then says "open in Word. Close it and retry" about a
Word that is not open; `readable()` snapshots a file nobody holds and
reports it read a snapshot. The write path knows this state —
`_replace_atomically` clears the read-only bit on exactly this error,
because OneDrive "flips it read-only mid-write" — so the package's own
account of the drive says the lock check will meet it.

## 5. `paper.toml` cannot be misspelt

`load_paper` reads every key with `.get` and a default:
`rescue_keep`, `doctor.skip`, `verify.commands`, `attic.path`, `batch.author`
… A typo takes the default silently, and a key that stops meaning
anything stays. The BACKLOG's workflow note names the cost — the U+2032
prohibition that outlived its reason by a month lived in this file —
and says "nothing gates a per-paper config". `doctor` is the natural
home: a `KNOWN` table per section, and an unknown key is a `Doubt`.
Effort S; it needs no new command.

## 6. The hang with no ceiling

`word.py` documents that Word's save path "can hang indefinitely" and
routes around it with Flat OPC. `CompareDocuments`, `Open` and
`ExportAsFixedFormat` have no such bypass and no deadline: `session()`
has no timer, records no pid, and the only ceiling anywhere is
`pytest-timeout`'s 300 s — which a paper script, `revision build` and
`validate` never run under. The pattern already exists one directory
over: `revision/_gates.py` runs a paper's gates with a deadline and
`_kill_tree`, and `test_revision_gates.py` proves an orphan is not left
behind. Applying it to the Word session is M: the pid at `DispatchEx`
time (measure whether `Application.Hwnd` answers for an invisible
instance), a worker thread, `taskkill /T` on expiry, and a `DocxKitError`
that names what was being compared.

## 7. `Any` where the stubs were meant to see

CONTRIBUTING: "Keep `lxml-stubs` installed — without it both checkers go
quiet on every lxml call." They also go quiet where the element arrives
as `Any`. `revisions.py` — the accept/reject engine under the reject-all
gate — declares `_lift_anchors(el: Any)`, `_content_elements(root: Any)`,
`_serialize(root: Any, …)`; `equations.py` 37 times, `lint.py` 19.
`word.py`'s 16 are COM and stay. `etree._Element` is the stub's name for
the rest; the change is mechanical and mypy/pyright are the test.

## 8. The type at the centre has no name

`dict[str, bytes]` is spelt 179 times, and 57 public functions take it
as their first parameter (83 take `xml: str`, 36 `args`, 21 a path, 14
a `Paper`). The 09-01 review said the three calling conventions were
not worth unifying, and that stands; this is not unification but a
name — `Parts` in `package`, re-exported — so griffe, a docstring and a
reader can refer to the thing every module passes around.

## 9. A drive letter in a template

`revision/_init.py:344` writes `attic = "D:\PaperAttic\<name>"` into
every scaffolded `paper.toml` when no attic is given. `_registry.py`
already derives its machine-wide path from `LOCALAPPDATA`/`XDG_DATA_HOME`;
the attic default belongs beside it, or the key should be absent until
the author sets one.

## What the mutants could not see, and why

`package.py` measured 4.5 % survival and `_table_layout.py` 4.8 % — both
worked, both closed rounds — and all three defects are in them. None is
a mutant's shape:

* a pattern that is wrong about the WORLD (which attribute Word writes
  first) is a corpus question; every mutation of `_TCW_RE` still matched
  every fixture, because the fixtures were written in the order the
  pattern expects;
* a write that is correct on every uninterrupted run has no failing
  test to kill it with; the property is what happens when it stops;
* a predicate that returns the right answer for the fixture it was
  written against (a locked file) and the wrong one for a state no
  fixture makes (a read-only file).

The gate that would have found each, in the cost order: the
order-bound-attribute count in `test_regex_registry.py` (one assertion);
an `os.replace`-raises test on `edit_in_place` (one test, the shape
exists); a read-only fixture beside every path predicate (one fixture).
The general form is the 2026-08-22 lesson: **a fix to one function is a
question to its siblings**, and the three siblings here were within
twelve lines, one module and one file of the fixes that missed them.

## Non-findings — measured, and not worth a batch

**The suite.** 31.5 s at eight workers; the slowest test is 6.2 s and it
is the one that proves a timed-out gate leaves no orphan. Nothing in
`tools/`' tests dominates. Fine as it is.

**The `revision` facade's 34 private re-exports.** The seam is honest:
tests reach 12 of them (19 times `revision._validate`) and the consumer
snapshot shows the papers reach none. The `_state` function-shadows-module
collision the 09-01 review recorded is still there and still costless.

**Regex growth.** 158 → 231 by the same count in nineteen days. The
self-closing registry holds over all of them, and order-boundness is
now measured at one pattern (§1). Not a consolidation problem; a
census-when-a-file-is-open problem.

**Two shapes of report.** `batch` returns `report.text()`;
`_compare_render.render` and `citations.check_citations` print. Worth
unifying when either is next open, not before.

**Root clutter.** 223 entries in the repo root, 11 tracked, all ignored;
the rest are `.mutation-*` sessions. A `.mutation/` directory is one
gitignore line and a base-dir argument. Ergonomics, not architecture.

**Source-reading tests.** 26 files, up one since 09-01. Watching, not
acting.

**The ledger.** Still write-only, correctly. Since 09-01 the open S2
(`build` silent on a pending working file) closed as `WorkingPending`,
exit 6 — by reading the FILE's own revision count, which is the
protocol's declared state rather than artifact inference. The ledger's
first reader has one fewer question to answer.

**Layering.** Fan-in unchanged in shape: `_xml` 36, `errors` 27, `find`
12; fan-out `cli` 29, `revision` 13, `tracked` 11. The declared cycle is
still exactly the declared cycle.
